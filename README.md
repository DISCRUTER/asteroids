# Asteroids
Clone of the retro **Asteroid** game, a game you may not remember but did exist!!

## Introduction
I made this game for completing a course on BootDev, and so naturally while majority of code being mine consist of helper code from them.

## Tech Stack
The game is made with PyGame.

## Prerequisites
You should have **`uv`** installed your pc.

## Installation
1) Clone the repo.
    ```bash
    $ git clone https://github.com/DISCRUTER/asteroids.git
    ```
2) Go to cloned folder and run
    ```bash
    uv sync
    ```
3) And now you are good to go, just run the game and enjoy.
    ```bash
    uv run main.py
    ```
## Controls
| Button | Usage |
|--------|-------|
| **W** | Move forward |
| **S** | Move backward |
| **A** | Turn anti-clockwise |
| **D** | Turn clockwise |

## Usage
The game will close when the player is hit **3** times.
